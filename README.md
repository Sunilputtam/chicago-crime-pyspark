# Chicago Crime Analysis Using PySpark

This project uses PySpark to clean, process, and analyze reported crime
data from the City of Chicago.

## Analysis

- Crime trends by year
- Crime distribution by hour of day
- Top 10 reported crime types
- Data visualization using Matplotlib

## Technologies

- Python
- PySpark
- Pandas
- Matplotlib
- Google Colab

## Dataset

The dataset is available from the
[Chicago Data Portal](https://data.cityofchicago.org/Public-Safety/Crimes-2001-to-Present/ijzp-q8t2).

The CSV file is not included in this repository because of its size.

## Running the Project

1. Download the dataset from the Chicago Data Portal.
2. Upload the CSV to Google Drive.
3. Open `Chicago_Crime_Analysis.ipynb` in Google Colab.
4. Update the `file_path` variable to match the CSV location.
5. Run the notebook cells in order.

## Key Findings

For the dataset snapshot used in the notebook:

- Theft was the most frequently reported crime type.
- Midnight had the highest recorded crime count by hour.
- Battery and criminal damage were also among the most common categories.

## Disclaimer

This project is for educational and exploratory analysis. The dataset
contains reported incidents and should not be interpreted as a complete
measurement of crime or public safety.
